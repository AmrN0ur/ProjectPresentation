نظام إدارة متكامل

نظام إدارة الكانتين والفروع
Canteen & Branch Management System

نظام ويب متكامل لإدارة المخزون الرئيسي والفروع، ومتابعة توزيع البضائع، وتحصيل الأموال، ومراقبة الأداء المالي لكل فرع بشكل واضح ومنظم.

فكرة النظام:
تنظيم العمل داخل الكانتينات التابعة للفروع المختلفة (الحضانات)، مع إدارة المخزون وتوزيع البضائع ومتابعة التحصيل المالي.

الجهات المستخدمة

2المالك + المحاسب

البيئة التقنية

Laravel+ Vue 3

مدة الاستضافة

6أشهر مجانية

طبيعة النظام

WebResponsive App

الأطراف المستخدمة للنظام

كل مستخدم له صلاحيات ووظائف محددة ضمن النظام.

المالك (Admin)مدير النظام

  • إدارة النظام بالكامل
  • إضافة المنتجات والبضائع للمخزن الرئيسي
  • إدارة الفروع (الحضانات)
  • متابعة الحسابات والأرباح
  • رؤية الإحصائيات والتقارير
  • تأكيد استلام الأموال من مسئول الحسابات

مسئول الحسابات (Accountant)محاسب

  • شراء البضائع وإضافتها للمخزن
  • توزيع البضائع على الفروع
  • تحصيل الأموال من الفروع
  • إرسال طلب تسليم الأموال للمالك
  • لا يمكنه رؤية الأرباح (قيود الصلاحيات)

المخزن الرئيسي والفروع

إدارة المخزون وتوزيع البضائع ومتابعة القيم المالية.

تسجيل المنتجات في المخزن

  • اسم المنتج وBarcode (اختياري)
  • عدد القطع داخل العبوة
  • سعر الشراء والبيع للقطعة
  • تسجيل الكميات على هيئة عبوات
  • عرض إجمالي قيمة المخزون
  • عرض صافي الربح المتوقع

توزيع البضائع على الفروع

  • تسليم البضائع للفروع مباشرة
  • تسجيل اسم الفرع والبضائع المسلمة
  • حساب القيمة المالية لكل فرع
  • متابعة الرصيد المتبقي في الفرع
  • الفرع يعامل كقيمة مالية فقط
  • لا يتم عرض تفاصيل الأصناف داخل الفرع

تحصيل وتحويل الأموال

  • تحصيل الأموال من الفروع بشكل دوري
  • تسجيل المبالغ المستلمة من كل فرع
  • تحديث رصيد الفرع تلقائياً
  • إضافة المبلغ إلى حساب المحاسب
  • إرسال طلب تحويل من المحاسب للمالك
  • تأكيد الاستلام من المالك ونقل الرصيد

نظام الإشعارات

  • تسجيل بضاعة جديدة في المخزن الرئيسي
  • تسليم بضاعة إلى أحد الفروع
  • استلام مبلغ من أحد الفروع
  • نجاح تحويل مبلغ من المحاسب للمالك
  • إشعارات فورية للمالك (Admin)

البيئة التقنية (Tech Stack)

تقنيات حديثة لبناء نظام قوي وسريع وقابل للتطوير.

الواجهة الأمامية (Frontend)

  • Vite - بناء سريع
  • Vue 3 - إطار العمل
  • Tailwind CSS - تصميم حديث
  • TailAdmin RTL - قالب متجاوب

الواجهة الخلفية (Backend)

  • PHP Laravel - إطار العمل
  • MySQL Database - قاعدة البيانات
  • API RESTful - تواصل آمن
  • Authentication - مصادقة محمية

الإحصائيات والتقارير

تقارير واضحة تساعد الإدارة على اتخاذ قرارات دقيقة.

إحصائيات الفروع

  • القيمة الحالية داخل كل فرع
  • متابعة رصيد الفروع
  • عرض منفصل لكل فرع

إحصائيات المحاسب

  • المبالغ التي تم تحصيلها
  • حساب المحاسب المالي
  • تاريخ التحصيلات

إحصائيات المالك

  • الحساب الخاص بالمالك
  • الأرباح والتحصيلات
  • ملخص الأداء المالي

الأمان وصلاحيات الدخول

  • لكل مستخدم حساب خاص
  • تسجيل دخول آمن
  • تغيير كلمة المرور
  • صلاحيات حسب الدور

الأجهزة المدعومة والاستضافة

نظام ويب متجاوب يعمل على جميع الأجهزة مع استضافة مجانية.

الأجهزة المدعومة

  • الهواتف الذكية (Mobile)
  • الأجهزة اللوحية (Tablet)
  • أجهزة الحاسوب المكتبية
  • واجهة متجاوبة Responsive
  • لا يتطلب تثبيت برامج

الاستضافة والتشغيل

  • خادم VPS تابع لفريق التطوير
  • 6 أشهر استضافة مجانية
  • بعدها: مشاركة التكلفة أو نقل النظام
  • إمكانية إعداد خادم داخل مقر العميل
