ما سيتم تنفيذه فعليًا داخل النظام

النطاق التالي مبني على ملفات العميل + تفريغ اجتماعات الفريق + مخطط سير العمل المعتمد.

1) نظام الهوية والصلاحيات

  • تسجيل الدخول والخروج الآمن مع عزل بيانات كل مشروع.
  • استعادة كلمة المرور عبر البريد الإلكتروني.
  • إنشاء حساب من الخارج.
  • إنشاء حسابات المقاولين والاستشاريين من داخل النظام.
  • صلاحيات RBAC ومنع الوصول المباشر للروابط غير المصرح بها.

2) إدارة المشاريع وبيانات BOQ

  • إنشاء مشروع جديد (اسم المشروع + وصف + بياناته الأساسية).
  • إدخال BOQ مباشرة أو عبر رفع Excel بالقالب المعتمد.
  • حقول البنود: item_code, description, unit, quantity, rate, amount.
  • حقول متابعة التنفيذ: actual_cost, completed_percentage, start_date, end_date.
  • عزل كامل لبيانات كل مشروع (Multi-project Isolation).

3) محرك EVM والتحليل المالي

  • حساب المؤشرات: EV, AC, PV, CPI, SPI, CV, EAC, BAC بشكل آلي.
  • لوحات وتقارير مقارنة المخطط مقابل الفعلي.
  • متابعة البنود للمقاول والاستشاري وربط التنفيذ بالتكلفة الفعلية.
  • تقارير مالية دورية للمالك لدعم القرار.

4) الحوكمة، التنبيهات، الأرشفة

  • سجل تدقيق محصن (Immutable Log) لتتبع جميع العمليات.
  • نظام تنبيهات للحالات الحرجة، التأخير، والمتابعة التشغيلية.
  • إدارة الصلاحيات للأدوار (مالك/مطور، مقاول، استشاري، إدارة).
  • حفظ دائم للملفات المرفوعة وربطها بسير المشروع.

5) الاشتراكات والدعم والتعدد اللغوي

  • متابعة الاشتراكات وإدارة مدفوعات النظام.
  • صفحة دعم فني وخدمة عملاء داخل المنصة.
  • دعم العربية والإنجليزية عبر ملفات JSON مرنة.
  • الالتزام بالقاموس المصطلحي المعتمد لتوحيد المصطلحات.

6) التحليلات التنبؤية ومخرجات التقارير

  • Predictive & Analysis Engine لاستخراج مؤشرات استباقية.
  • تحليل البيانات القادمة من ملفات Excel وPDF.
  • تصدير تقارير بصيغ تشغيلية (PDF / Excel / JSON).
  • تسليم نهائي يشمل الكود والتوثيق التشغيلي المطلوب.

خطة التنفيذ على 4 دفعات تسليم

في نهاية كل دفعة: تسليم الجزء المنجز بالكود + مراجعة واعتماد + استلام قيمة الدفعة.

الدفعة الأولى: MVP Core

المرحلة التأسيسية
  • تسجيل الدخول والخروج.
  • استعادة كلمة المرور.
  • إنشاء حساب من الخارج.
  • إنشاء حسابات المقاولين والاستشاريين من الداخل.
  • إطلاق النسخة الأساسية من محرك EVM كقلب النظام.
استحقاق الدفعة: بعد تسليم كود الـMVP واجتياز مراجعة العميل.

الدفعة الثانية: إدارة التشغيل اليومي للمشروع

تشغيل أساسي
  • إضافة المشاريع وإدخال البيانات الأساسية.
  • نموذج BOQ (إدخال مباشر + رفع Excel مع التحقق).
  • شاشات متابعة البنود للمقاول والاستشاري.
  • التقارير المالية المبدئية (المخطط مقابل الفعلي).
استحقاق الدفعة: بعد التسليم واعتماد نطاق المرحلة الثانية.

الدفعة الثالثة: الحوكمة والرقابة المتقدمة

رقابة واستقرار
  • لوحة المالك لمتابعة الأداء والمخاطر والمؤشرات.
  • نظام الإشعارات والتنبيهات للأدوار المختلفة.
  • إدارة الصلاحيات وسجل التدقيق المحصن.
  • أرشفة الملفات وتفعيل إدارة الاشتراكات.
استحقاق الدفعة: بعد تسليم التكامل التشغيلي واعتماد نتائج الاختبار.

الدفعة الرابعة: الإطلاق والتحليلات النهائية

تسليم نهائي
  • تفعيل محرك التحليل والتنبؤ (Predictive Engine).
  • التقارير النهائية والتصدير متعدد الصيغ.
  • صفحات الدعم الفني والتعدد اللغوي الكامل.
  • تسليم الكود النهائي والوثائق الفنية المعتمدة.
استحقاق الدفعة: بعد التسليم النهائي واعتماد الإغلاق الفني للمشروع.

  • الاعتماد: كل دفعة تُغلق بمحضر اعتماد مرحلة قبل بدء المرحلة التالية.

آلية بدء المشروع والتعاقد

  • سيتم إعداد عقد رسمي يوضح نطاق التنفيذ، آلية التسليم، جدول الدفعات، والالتزامات المتبادلة.
  • يبدأ تنفيذ المشروع بعد توقيع العقد بيوم عمل واحد.
  • أي تعديل على النطاق بعد التوقيع يتم عبر ملحق تعاقدي واضح (مدة/تكلفة).
  • هذا العرض يمثل الإطار التنفيذي المعتمد لاتخاذ قرار البدء.

لماذا هذا العرض كافٍ لاتخاذ قرار البدء؟

  • يوضح بدقة ماذا سيُنفذ داخل النظام فعليًا.
  • يربط كل دفعة بتسليم ملموس وقابل للاختبار.
  • يحدد السعر والمدة وحدود ما هو خارج النطاق.
